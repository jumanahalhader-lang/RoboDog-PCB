# RoboDog-PCB
PCB A custom PCB designed for a robotic dog project, featuring four servo motor connections for leg movement and an HC-SR04 ultrasonic sensor for distance detection. The PCB is designed to organize and simplify the robot’s wiring and component connections.

## Components 
- Arduino Nano
- AltraSonic
- 3P Female Or Male pins
- Voltage Regulator
